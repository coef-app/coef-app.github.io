Calculer une intégrale

Si F est une primitive de f sur [a;b], alors ∫abf(x)dx=F(b)−F(a) ; pour une fonction positive, c’est une aire sous la courbe, en unités d’aire.

En 3 étapes

  1. Trouve une primitive avec les formules : xn a pour primitive xn+1n+1, ex a pour primitive ex, 1x a pour primitive ln(x) sur ]0;+∞[.
  2. Écris le crochet [F(x)]ab, puis calcule F(b)−F(a).
  3. Pour une aire entre deux courbes, intègre la différence (celle du dessus moins celle du dessous).
Exemple

Calcule ∫01(2x+ex)dx.

Une primitive de x↦2x+ex est F:x↦x2+ex. Donc ∫01(2x+ex)dx=[x2+ex]01=(1+e)−(0+1)=e.

Le piège

Oublier F(a), surtout quand a=0 mais que F(0) ne vaut pas 0 (ici e0=1). Et une intégrale peut être négative : une aire, jamais.
