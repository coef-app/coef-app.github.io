Partir, explorer, migrer

Dans les littératures de langue anglaise, voyager, c’est explorer l’inconnu, chercher une vie meilleure, ou se chercher soi-même. Les frontières se franchissent, se ferment ou se rêvent.

Explorer, se dépayser, rêver

  • Thomas More, dans Utopia (1516), invente une île à la société idéale ; le mot, forgé sur le grec, signifie « nulle part ».
  • Robinson Crusoe, de Daniel Defoe (1719) : le naufragé recrée une civilisation sur son île.
  • Gulliver’s Travels, de Jonathan Swift (1726) : les pays imaginaires servent à faire la satire de l’Angleterre.
  • Heart of Darkness, de Joseph Conrad (1899) : la remontée d’un fleuve africain dévoile la violence de la colonisation.

Migrer

  • Les Pères pèlerins traversent l’Atlantique sur le Mayflower en 1620.
  • Ellis Island, dans le port de New York, accueille des millions d’immigrants de 1892 à 1954 ; dans The Godfather: Part II (Coppola, 1974), le jeune Vito y arrive en 1901.
  • Aujourd’hui, les murs et les contrôles aux frontières, entre les États-Unis et le Mexique par exemple, posent la question de l’accueil.

Le voyage intérieur

  • Adventures of Huckleberry Finn, de Mark Twain (1884) : la descente du Mississippi en radeau, avec Jim, un esclave en fuite, est aussi une éducation morale.
  • On the Road, de Jack Kerouac (1957) : la traversée de l’Amérique, quête de liberté de la Beat Generation.

Quels connecteurs pour croiser deux documents sur le voyage ?

Pour rapprocher : « Both documents… », « Similarly, … », « This echoes… ». Pour opposer : « Whereas…, … », « Unlike… », « On the contrary, … ». Pour nuancer : « However, … », « Yet, … ». Par exemple : « Whereas Ántonia’s family settles in the plains, young Vito has only just set foot on Ellis Island. »

À retenir

  • Explorer et rêver : More (1516), Defoe (1719), Swift (1726), Conrad (1899).
  • Migrer : le Mayflower (1620), Ellis Island (1892-1954).
  • Le voyage intérieur : Twain (1884), Kerouac (1957).
  • Les connecteurs : both, similarly, whereas, unlike, however.
