Les graphes

Un graphe relie des sommets par des arêtes (des arcs s’il est orienté), parfois pondérées. On le représente par une matrice d’adjacence ou par une liste d’adjacence (un dictionnaire en Python). On le parcourt en largeur, avec une file, ou en profondeur, avec une pile ou par récursivité.

Le vocabulaire

  • Deux sommets reliés sont voisins ; le degré d’un sommet est son nombre de voisins.
  • Un chemin suit des arêtes ; un cycle revient à son point de départ (ici A, B, D, C, A).
  • Un graphe est connexe si un chemin relie toujours deux sommets quelconques.

Deux représentations

ABCDE
A01100
B10010
C10011
D01100
E00100

La matrice d’adjacence met un 1 à la ligne i, colonne j, si i et j sont reliés ; pour un graphe non orienté, elle est symétrique. La liste d’adjacence donne, pour chaque sommet, la liste de ses voisins : elle prend moins de place quand il y a peu d’arêtes.

g = {"A": ["B", "C"],
     "B": ["A", "D"],
     "C": ["A", "D", "E"],
     "D": ["B", "C"],
     "E": ["C"]}

Les parcours

from collections import deque

def largeur(graphe, depart):
    vus = [depart]
    file = deque([depart])
    while file:
        s = file.popleft()
        for v in graphe[s]:
            if v not in vus:
                vus.append(v)
                file.append(v)
    return vus

def profondeur(graphe, s, vus=None):
    if vus is None:
        vus = []
    vus.append(s)
    for v in graphe[s]:
        if v not in vus:
            profondeur(graphe, v, vus)
    return vus
Exemple

Dans quel ordre chaque parcours visite-t-il le graphe, depuis A ?

En largeur : A, puis ses voisins B et C, puis D (voisin de B) et E (voisin de C) : A, B, C, D, E. En profondeur : A, B, puis D (voisin de B), puis C (voisin de D), puis E : A, B, D, C, E. Le parcours en largeur trouve les sommets par distance croissante au départ.

À retenir

  • Sommets, arêtes (arcs si orienté), poids ; voisins, degré, chemin, cycle, connexe.
  • Matrice d’adjacence ou liste d’adjacence (un dictionnaire).
  • Largeur : une file ; profondeur : une pile ou la récursivité.
  • Le parcours en largeur donne les plus courts chemins en nombre d’arêtes.
