Les arbres binaires et les arbres binaires de recherche

Un arbre binaire est vide, ou fait d’une racine et de deux sous-arbres, gauche et droit. On le parcourt en profondeur (préfixe, infixe, suffixe) ou en largeur. Dans un arbre binaire de recherche, tout ce qui est à gauche d’un nœud est plus petit, tout ce qui est à droite plus grand : on y cherche une valeur en descendant une seule branche.

Le vocabulaire

  • La racine est le nœud du haut ; une feuille n’a aucun enfant.
  • La taille est le nombre de nœuds (9 ici).
  • La hauteur dépend de la convention de l’énoncé : le nombre de nœuds de la plus longue branche (4 ici), ou son nombre d’arêtes (3). Lis toujours la définition donnée.

Les parcours

ParcoursOrdreSur l’exemple

Dans un arbre binaire de rechercheLe parcours infixe donne les valeurs dans l’ordre croissant.

En Python

class Noeud:
    def __init__(self, valeur,
                 gauche=None, droit=None):
        self.valeur = valeur
        self.gauche = gauche
        self.droit = droit

def taille(arbre):
    if arbre is None:
        return 0
    return (1 + taille(arbre.gauche)
              + taille(arbre.droit))

def recherche(arbre, x):
    if arbre is None:
        return False
    if x == arbre.valeur:
        return True
    if x < arbre.valeur:
        return recherche(arbre.gauche, x)
    return recherche(arbre.droit, x)
Exemple

Combien de nœuds la recherche de 7 visite-t-elle dans l’arbre du schéma ?

8 (7 est plus petit : à gauche), 3 (7 est plus grand : à droite), 6 (à droite), puis 7 : trouvé, après 4 nœuds. Le coût est au plus la hauteur de l’arbre : environ log2n si l’arbre est équilibré, mais jusqu’à n s’il est filiforme.

À retenir

  • Taille : le nombre de nœuds ; hauteur : selon la convention de l’énoncé.
  • Préfixe (nœud d’abord), infixe (nœud au milieu), suffixe (nœud à la fin), largeur (une file).
  • ABR : plus petit à gauche, plus grand à droite ; l’infixe est trié.
  • Rechercher dans un ABR : une seule branche, au plus la hauteur.
