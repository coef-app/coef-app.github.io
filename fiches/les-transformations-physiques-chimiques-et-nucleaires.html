Les transformations physiques, chimiques et nucléaires

Une transformation physique change l’état d’une espèce sans la changer ; une transformation chimique change les espèces, mais garde les éléments ; une transformation nucléaire change les noyaux, donc les éléments eux-mêmes.

Les changements d’état

  • Solide vers liquide : la fusion ; liquide vers gaz : la vaporisation ; solide vers gaz : la sublimation ; et les inverses, solidification, liquéfaction, condensation.
  • Fondre ou vaporiser demande de l’énergie : la transformation est endothermique. L’énergie vaut Q=m×L, où L est l’énergie massique de changement d’état.
Exemple

Quelle énergie faut-il pour faire fondre 200 g de glace ? (L = 334 kJ/kg)

Q=0,200×334=66,8 kJ.

Les transformations chimiques

  • Les réactifs se transforment en produits ; l’équation est ajustée quand chaque élément, et la charge, se conservent : CH4+2O2→CO2+2H2O.
  • Le réactif limitant est celui qui est entièrement consommé : il arrête la transformation.
Exemple

On fait brûler 2 mol de méthane avec 3 mol de dioxygène. Quel est le réactif limitant ?

L’équation dit qu’il faut 2 mol de dioxygène par mole de méthane : pour 2 mol de méthane, il en faudrait 4. Il n’y en a que 3 : le dioxygène est limitant. Il consomme 1,5 mol de méthane (il en reste 0,5 mol) et produit 1,5 mol de dioxyde de carbone et 3 mol d’eau.

Les transformations nucléaires

  • Des isotopes ont le même Z mais pas le même A : le carbone 12 et le carbone 14.
  • Dans une réaction nucléaire, le nombre de masse et le numéro atomique se conservent.
  • La fission casse un gros noyau (l’uranium 235, dans les centrales) ; la fusion unit de petits noyaux (l’hydrogène en hélium, dans le Soleil). Les deux libèrent une énergie énorme.

À retenir

  • Physique : l’état change ; Q=m×L.
  • Chimique : les espèces changent, les éléments se conservent ; le réactif limitant.
  • Nucléaire : les noyaux changent ; Z et A se conservent.
  • Fission (uranium) et fusion (Soleil).
