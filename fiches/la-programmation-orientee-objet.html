La programmation orientée objet

Une classe décrit un type d’objets : leurs attributs (leurs données) et leurs méthodes (ce qu’ils savent faire). Chaque objet créé à partir d’elle est une instance, avec ses propres valeurs d’attributs. Le constructeur __init__ les initialise ; self désigne l’objet lui-même.

Classe, attributs, méthodes

class Compte:
    def __init__(self, titulaire, solde=0):
        # des attributs
        self.titulaire = titulaire
        self.solde = solde

    # une méthode
    def deposer(self, montant):
        self.solde = self.solde + montant

    def retirer(self, montant):
        if montant > self.solde:
            return False
        self.solde = self.solde - montant
        return True
  • class Compte définit la classe ; Compte("Léa", 50) crée une instance.
  • __init__ est le constructeur : il est appelé à la création et initialise les attributs.
  • self est le premier paramètre de chaque méthode : l’objet sur lequel elle agit. On écrit c.deposer(20), et Python passe c comme self.

Utiliser des objets

c = Compte("Léa", 50)
c.deposer(20)
print(c.solde)         # 70
print(c.retirer(100))  # False
Exemple

Deux comptes a = Compte("Ali") et b = Compte("Inès", 30) sont créés, puis a.deposer(10). Que vaut b.solde ?

30 : chaque instance a ses propres attributs. Déposer sur a ne change rien à b.

Pourquoi des objets

  • Regrouper des données et les fonctions qui les manipulent.
  • L’encapsulation : on utilise un objet par ses méthodes (son interface), sans dépendre de la façon dont il est codé à l’intérieur.
  • Les structures de données (une pile, un arbre) s’écrivent naturellement comme des classes.

À retenir

  • Une classe : des attributs et des méthodes ; un objet en est une instance.
  • __init__ initialise les attributs ; self désigne l’objet.
  • objet.methode(…) : Python passe l’objet comme self.
  • Encapsulation : on passe par l’interface, les méthodes.
