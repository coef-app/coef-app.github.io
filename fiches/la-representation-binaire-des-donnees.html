La représentation binaire des données

Toute donnée est codée en binaire, avec des 0 et des 1. Les entiers positifs s’écrivent en base 2, les entiers relatifs en complément à deux, les réels de façon approchée en virgule flottante, les caractères par des codes (ASCII, Unicode). Les booléens se combinent avec et, ou, non.

Les bases

  • Un bit vaut 0 ou 1 ; un octet compte 8 bits, donc 28=256 valeurs.
  • En base 2, chaque chiffre est une puissance de 2 : 1011112=32+8+4+2+1=47.
  • En base 16 (l’hexadécimal), les chiffres vont de 0 à 9 puis de A à F (A = 10, …, F = 15). Un chiffre hexadécimal remplace quatre bits : 0x2F = 2×16+15=47.

Les entiers relatifs : le complément à deux

  • Sur n bits, on code les entiers de −2n−1 à 2n−1−1 : de −128 à 127 sur 8 bits.
  • Pour coder un négatif −x : écrire x en binaire, inverser tous les bits, ajouter 1.
  • Le bit de gauche vaut 1 pour un négatif.
Exemple

Code −5 en complément à deux sur 8 bits.

5 s’écrit 00000101. On inverse : 11111010. On ajoute 1 : 11111011. Vérification : 111110112+000001012 donne 100000000, dont on ne garde que les 8 bits de droite : 0.

Les flottants

Un réel est codé en virgule flottante (la norme IEEE 754) : un signe, un exposant et une mantisse, comme une écriture scientifique en base 2. Beaucoup de nombres, comme 0,1, n’ont pas d’écriture binaire finie : ils sont arrondis.

>>> 0.1 + 0.2
0.30000000000000004
>>> 0.1 + 0.2 == 0.3
False
À retenirOn ne teste jamais l’égalité de deux flottants : on vérifie que leur écart est très petit, par exemple abs(a - b) < 1e-9.

  • L’ASCII code 128 caractères sur 7 bits (« A » vaut 65).
  • Unicode donne un numéro à tous les caractères du monde ; UTF-8 les code sur 1 à 4 octets, en gardant l’ASCII sur un seul.

À retenir

  • Base 2 : des puissances de 2 ; base 16 : un chiffre pour quatre bits.
  • Complément à deux : inverser les bits, ajouter 1 ; de −128 à 127 sur 8 bits.
  • Flottants : des valeurs approchées ; jamais de test d’égalité.
  • Booléens : et, ou, non, ou exclusif ; caractères : ASCII, Unicode et UTF-8.
