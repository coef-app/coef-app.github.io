Les structures de données linéaires : listes, piles, files, dictionnaires

Une structure de données se définit par son interface (ce qu’on peut faire) avant son implémentation (comment c’est codé). Une pile sort le dernier élément entré, une file le premier ; un dictionnaire associe des valeurs à des clés et les retrouve très vite.

Piles et files

pile = []
pile.append(3)       # empiler
pile.append(5)
sommet = pile.pop()  # dépiler : 5

from collections import deque
file = deque()
file.append(3)       # enfiler
file.append(5)
premier = file.popleft()  # 3
  • Une pile sert à annuler la dernière action, à revenir en arrière dans un navigateur, à gérer les appels de fonctions.
  • Une file sert à traiter des demandes dans leur ordre d’arrivée : une file d’impression, le parcours en largeur.

Une pile au travail

def equilibre(texte):
    pile = []
    for c in texte:
        if c == "(":
            pile.append(c)
        elif c == ")":
            if not pile:
                return False
            pile.pop()
    return not pile
Exemple

Que renvoient equilibre("(()())") et equilibre("())(") ?

True pour le premier : chaque parenthèse fermante trouve une ouvrante dans la pile, et la pile finit vide. False pour le second : à la troisième parenthèse, une fermante arrive sur une pile vide.

Listes et dictionnaires

  • Une liste chaînée relie chaque élément au suivant : ajouter en tête est immédiat, mais atteindre le k-ième élément demande de parcourir les k premiers.
  • Un dictionnaire associe une valeur à chaque clé : notes = {"maths": 14, "nsi": 17}, puis notes["nsi"] vaut 17. L’accès par clé est très rapide, quelle que soit la taille.

À retenir

  • Interface (les opérations) et implémentation (le code) sont distinctes.
  • Pile : LIFO, append et pop ; file : FIFO, append et popleft d’un deque.
  • Liste chaînée : ajout en tête immédiat, accès au k-ième en parcourant.
  • Dictionnaire : des couples clé-valeur, un accès rapide par la clé.
